ExCas-Analyzer

A browser-based tool for quantifying CRISPR-induced large deletions from paired-end amplicon sequencing. Your sequencing files never leave the machine — a WebAssembly module inside a Web Worker does all the work.

Input format follows Cas-Analyzer (RGEN Tools).
Example data

Three published targets, all SpCas9 (5'-NGG-3') on the minus strand. Download the files to try the form yourself, or load a set straight into the analyzer.

Basic Information

To detect large deletions, include several kb on both sides of the cleavage site. Or upload a FASTA file:

The PAM is used only to locate the target and derive the cleavage site.

Both strands of the reference are searched; coordinates and the cleavage site are derived automatically.

Used as the SAM reference name and in the output file names.
